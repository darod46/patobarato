# Portadas de las guías de neumáticos: prompts para Gemini

Mismo procedimiento y mismo bloque de estilo que `docs/guias-portadas-prompts.md` (adjunta `web/public/og.png` como referencia). 16:9, sin texto. Guarda cada PNG/JPEG como `web/public/guias/<slug>.jpeg` y añade el slug a `web/src/lib/guide-covers.ts` (hasta entonces la guía sale sin portada, nunca con una imagen rota).
